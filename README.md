# 十二星座 · 三日运势 · 全盘解读

一张自包含的网页：12 星座性格 / 爱情 / 事业方向，2026-11-16 → 11-18 三日运势，上升星座计算器，五行属性与特征分析，对应宫位与天干，以及一张真正算出来的星盘轮盘。

无外部依赖、无 CDN、无追踪 —— 单个 `index.html`，双击即可离线打开。

## 数据怎么来的

- 行星位置：内置 Schlyter 低精度轨道根数（含月球主要摄动项），页面加载时实时计算，误差约 1′–3′ 量级；已与独立 Python 实现对拍一致（太阳天蝎 23°48′、月亮水瓶 11°14′、金星停滞 0°06′/日等）。
- 上升/中天：JD → GMST → RAMC → `atan2(cos RAMC, −(sin RAMC·cos ε + tan φ·sin ε))`。
- 三日运势：按行运星落各星座第几宫逐条推出，属解释层，不是数据层。
